# Licensed inputs for the authored reconstruction

Recorded 2026-09-29. Game layout, progression, dialogue, geometry assembly, shaders and authoring scripts are produced in this workspace. Selected environment and anatomy inputs are third-party CC0 assets; they are **not original meshes created here and are not recovered Nintendo game data**.

## Runtime environment inputs

Files beneath `game/assets/natural/`:

- [Rock Face 01 — Poly Haven](https://polyhaven.com/a/rock_face_01), Dario Barresi: scanned rock geometry and diffuse, normal and packed surface textures.
- [Rocky Terrain 02](https://polyhaven.com/a/rocky_terrain_02), [Cobblestone Floor 08](https://polyhaven.com/a/cobblestone_floor_08), [Slab Tiles](https://polyhaven.com/a/slab_tiles), [Medieval Blocks 05](https://polyhaven.com/a/medieval_blocks_05), Poly Haven: selected 2K diffuse, OpenGL normal and AO/roughness/metal maps. Earlier material alternatives are retained as source assets.

Poly Haven identifies these assets as [CC0](https://docs.polyhaven.com/en/faq). The authored scene changes placement, scale and material settings; it does not assert ownership of the underlying scans.

## Anatomical player — integrated in source, quality still in progress

`production/authored/link-study/link-anatomical.blend` and `.glb` combine MakeHuman graphical data with authored garments, rig setup and animation studies. The player now loads `game/assets/link_anatomical.glb`. The older `game/assets/link.glb` remains for the prior version and related NPC assets. The anatomy integration is unfinished in visual quality; it is not original Nintendo data.

- MakeHuman base mesh, child morph, default rig and skin weights: repository revision `a8bc2d54ff0ac92e78ff71431b1023eda42bf482`.
- Skin, short hair, high-resolution eyes, the adapted upper garment from male_casualsuit04 and their fitting data: [MakeHuman system assets CC0 pack](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html).
- The [MakeHuman license](https://github.com/makehumancommunity/makehuman/blob/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/LICENSE.md) distinguishes CC0 graphical assets from AGPL program code. This production path uses the graphical data; no MakeHuman application code is included in the runtime.

The original inputs remain unchanged in `production/reference-assets/`. `manifest.json` records their URLs and SHA-256 hashes. The downloaded archive also remains intact. The six repository files were compared byte for byte with the pinned revision. The selected archive members were compared against the original ZIP.

## Reference photography only

The [National Park Service photograph of Evans Plunge](https://npgallery.nps.gov/AssetDetail/011d7b74-155d-4519-3ee0-6e6bec9911b8), also [catalogued by Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Caver_Karen_Rosga_sits_on_the_edge_of_Evans_Plunge,_one_of_Wind_Cave%27s_lakes._(011d7b74-155d-4519-3ee0-6e6bec9911b8).jpg), is retained as a visual reference in `production/reference-assets/evans-plunge-nps.jpg`. It is not a game texture or runtime asset. The catalogue records it as a US government public-domain photograph.

Observed features: irregular layered rock, undercuts and fractures; small wet highlights; a visible rocky bed through clear foreground water; much darker unlit distance. These observations guide the study. They do not establish that the current render achieves the same realism.

Two additional public-domain Met Open Access photographs are reference-only: [incised leather boot 90.5.36b](https://www.metmuseum.org/art/collection/search/443620) and [early 19th-century leather boots 13.49.37a, b](https://www.metmuseum.org/art/collection/search/98235). Their period and function differ from the fictional character; they inform leather construction, not a claim of historical costume accuracy. Observed features include the sole-to-upper seam, shaped heel and toe, overlapping edges, rear/side joining seams, a thin rolled opening, creases around the flexing upper and irregular worn gloss. The present character study lacks much of this construction and material detail.

## Reproduction

From `ocarina-of-time/`:

```sh
python3 production/authored/fetch_reference_assets.py
blender --background --python production/authored/make_link_anatomical.py
```

The fetch script verifies every recorded SHA-256, preserves existing files and extracts only selected members from the system asset pack. It does not fetch ROMs. The Blender source retains packed images, rig and ten motion clips. `make_equipment.py` authors the sword, scabbard and wooden shield separately; `production/authored/equipment/equipment.blend` is their editable source. Garment microstructure textures and equipment grain are generated by these authoring scripts. In-game motion is integrated; final character quality remains pending.
